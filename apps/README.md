## ひらめっと本体へ移した部分（Qalc の合体 段階1・2・3・4・5）

Qalc（MIT © 2026 GIGAyama、commit 813bbc5）の遊び方を参考に、計算スプリント（index.html）へ次の3つを作り直して入れました。コードは React から書き直しており、Qalc のファイルはそのまま使っていません。

- タイムアタック（20問をどれだけ速く解けるか）
- サドンデス（1問まちがえたら終わり。連続正解数をきそう）
- にがて克服ボックス（まちがえた問題を最新50問まで自動でためる。正解すると消える）→ ひらめっとでは「にがて ボックス」

ひらめっと側の変更：コインは入れず、どんぐり・メダルの決まりはそのまま。タイムアタックの記録は16問以上正解のときだけ。サドンデスとにがて ボックスの回は単元の「できた」に入れません。授業モード（課題リンク）では使えません。ライセンス全文は `vendor/THIRD-PARTY-LICENSES.txt`。

### 段階2：かんがえるどうぐ → 「🧰 ずで かんがえる」

Qalc の「かんがえるどうぐ」（`src/LearningTools.jsx`・`src/learningTools/detect.js`、MANUAL.md 6章）を参考に、よく使う5つを `data/tools-viz.js` に vanilla JS（SVG）で作り直しました。Qalc のファイルはそのまま使っていません。

- ブロック（20までのたし算・ひき算、10の合成）、さくらんぼ（くり上がり・くり下がり）、アレイ（九九・□のかけ算・わり算とあまり・かけ算わり算の文章題）、くらい（位取り表）、ぶんすう（分数バー。分母がちがうときは「こまかく わける」）
- どの図を出すかは、問題文より先に単元ID・ひっ算のデータ（数と演算）で決め、なければ Qalc と同じように問題文から読みます。合う図が無い問題ではボタンを出しません。ひっ算の図は、問題がもう たての形で出ているので入れていません。

ひらめっと側の変更：電球（💡）は単元の例題ボタンに使っているので 🧰 にしました。図を開いた問題は「ヒントあり」で、答えた数には入りますが、単元の「できた」・メダル・自己ベストの正解には数えません。タイムアタックは記録に残さず、サドンデスは使えます。Qalc に無い、先生が切るスイッチ（その他の設定・リンクの `&tool=0`。オフが優先）を付けました。

### 段階3：みんなで → 友だち対戦の「ボスバトル」「じんとりバトル」

Qalc の「ボスバトル」「じんとりバトル」（`src/BossBattle.jsx`・`src/TerritoryBattle.jsx`・`src/battles/raidLogic.js`・`src/battles/territoryLogic.js`、MANUAL.md 5章）の決まりを参考に、部屋の進行を `data/cooplib.js`（先生の端末と `server.js` で同じ部品）に、画面を `index.html` に作り直しました。Qalc のファイル・絵（ボスのドット絵・キャラクター）はそのまま使っていません。ボスの絵は SVG で描きなおしたものです。

- ボスバトル（協力）：Qalc の「ボスの体力は人数で決まり、ステージごとに増える」「連続正解でダメージが増える」を使いました。
- じんとりバトル（2チーム）：Qalc の 7×7 の盤・本陣・マスごとに必要なぬりの数（ふつう2・★4・まんなか6）・うばうと+1・はなれたマスは+1・ぬれたらとなりにインクがはねる・のこり30秒のラストスパート（2倍）・自動のねらいマス（となりで のこりが少なく点が大きいマス）を使いました。

ひらめっと側の変更：ボスは「いたずらモンスター」で、正解で「くすぐる」と げんきがへり、0になると笑ってにげていきます（たおす・こうげきの言葉は使いません）。ボスがチームのHPを減らす攻撃・答えを止める妨害は入れず、「いたずら」は見た目だけ（点数・問題は変わらない）。1人が出せる量に上限をつけ、順位は出しません。じんとりは、ぬる場所を子どもが選べず（自動）、スペシャル技と？マス（運で決まる効果）を入れず、ぬったばかりのマスは15秒うばえない保護と、人数のちがうチームの力をそろえる補正を足しました。マスの判定は「調べる順番であか・あおに差が出ない」形に直しています。チームは先生の端末で分け（自動・1人ずつ移動）、児童の端末には自分のチームだけが届きます。児童が送るのは、ほかの対戦と同じく「答えた（正解かどうか・連番）」だけです。

### 段階4：きせかえ → ひろばの おみせの「きせかえ」（どんぐり）

ひらめっと側の変更：お金は どんぐり（1日20こまで）にまとめ、Qalc のコイン・ガチャ・レア度・レベルは入れていません。値段は 3〜15こ（はじめの どんぐり5こで1つ買える・1日1〜3こなら1週間に数こ）。12品は買わずに学びでもらえます（単元の「できた」の数・「マスター」の数・まなびっことの「なかよし」）。期間限定・セール・順位・自由な文字は ありません。買った物はなくならず、いつでもつけかえられます。名前の よこの称号は 決まった表の ことばだけです。友だち対戦で送るのは、つけている「ぼうし」の品のID だけ（表にある ぼうしだけ通す）。先生のオフ・授業モードでは ひろばごと出ません。ひろばが完成したあとも、まだ買っていない きせかえがあるあいだは どんぐりがふえます。記録は `mh_col` の `kz`、ひろばの文字は きせかえがあるときだけ HR3（HR1・HR2 もこれまでどおり読めます）。

### 段階6：Qalc のアプリ本体をはずす（2026-11-17）

Qalc（https://github.com/GIGAyama/Qalc 、commit 813bbc5、MIT © 2026 GIGAyama）の良い部分を段階1〜5で本体へ移したので、`apps/qalc/` に置いていたビルド済みのアプリと、ホームの「Qalc（カルク）」タイルをはずしました。
`apps/qalc/` には、前のアドレスを開いた人を算数の単元えらびへ案内するページ（index.html）と、前の Qalc のサービスワーカーを止めるだけの sw.js を残しています。消すのは `qalc-cache-` で始まる Qalc 自身のキャッシュだけで、端末に残る Qalc の記録（`qalc_*`）は消さず、移しもしません。
