## まなびひろば本体へ移した部分（Qalc の合体 段階1・2）

Qalc（MIT © 2026 GIGAyama、commit 813bbc5）の遊び方を参考に、計算スプリント（index.html）へ次の3つを作り直して入れました。コードは React から書き直しており、Qalc のファイルはそのまま使っていません。

- タイムアタック（20問をどれだけ速く解けるか）
- サドンデス（1問まちがえたら終わり。連続正解数をきそう）
- にがて克服ボックス（まちがえた問題を最新50問まで自動でためる。正解すると消える）→ まなびひろばでは「にがて ボックス」

まなびひろば側の変更：コインは入れず、どんぐり・メダルの決まりはそのまま。タイムアタックの記録は16問以上正解のときだけ。サドンデスとにがて ボックスの回は単元の「できた」に入れません。授業モード（課題リンク）では使えません。ライセンス全文は `apps/qalc/LICENSE.txt` と `vendor/THIRD-PARTY-LICENSES.txt`。

### 段階2：かんがえるどうぐ → 「🧰 ずで かんがえる」

Qalc の「かんがえるどうぐ」（`src/LearningTools.jsx`・`src/learningTools/detect.js`、MANUAL.md 6章）を参考に、よく使う5つを `data/tools-viz.js` に vanilla JS（SVG）で作り直しました。Qalc のファイルはそのまま使っていません。

- ブロック（20までのたし算・ひき算、10の合成）、さくらんぼ（くり上がり・くり下がり）、アレイ（九九・□のかけ算・わり算とあまり・かけ算わり算の文章題）、くらい（位取り表）、ぶんすう（分数バー。分母がちがうときは「こまかく わける」）
- どの図を出すかは、問題文より先に単元ID・ひっ算のデータ（数と演算）で決め、なければ Qalc と同じように問題文から読みます。合う図が無い問題ではボタンを出しません。ひっ算の図は、問題がもう たての形で出ているので入れていません。

まなびひろば側の変更：電球（💡）は単元の例題ボタンに使っているので 🧰 にしました。図を開いた問題は「ヒントあり」で、答えた数には入りますが、単元の「できた」・メダル・自己ベストの正解には数えません。タイムアタックは記録に残さず、サドンデスは使えます。Qalc に無い、先生が切るスイッチ（その他の設定・リンクの `&tool=0`。オフが優先）を付けました。
