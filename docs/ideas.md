  - 決めた方法：**新しい住所は Cloudflare Pages（同じリポジトリとつなぐ）／古い住所（github.io）は「引っ越し係」のページ**にする
    - GitHub Pages の独自ドメイン設定（サーバーがすぐ飛ばす）は使わない → 古いページが開かれず、localStorage の記録を運び出せないため
    - 引っ越し係：古い住所を開いたら、その端末の記録をまとめて URL の「#」の後ろに入れて新しい住所へ（サーバーには届かない）。新しい住所で受けとって、今ある記録と合わせて保存（減らさない）。`#u=…` など続きも引きつぐ
  - 順番：①あなたがドメインを買う → ②バックアップに残りの記録を入れる → ③引っ越し係と受けとりを作る（ブランチ）→ ④あなたが Cloudflare Pages をつなぐ → ⑤名前の変更・ロゴといっしょに公開 → ⑥Search Console を新しい住所で登録
