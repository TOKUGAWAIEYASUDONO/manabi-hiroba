# 算数単元の分類の参考

以下は単元をどんな段階に分けるか、数の範囲や繰り上がり・繰り下がりの条件を考えるための参考資料です。問題文・図・PDFは転載していません。問題の数は生成時に乱数で作ります。

- [すらすらプリント（すらぷり）](https://surapuri.jp/elementary_school02/hissan-p/) — 筆算の段階分け。
- [ぷりんときっず](https://print-kids.net/print/sansuu/tashi-hiki-hissan/) — 桁数と繰り上がり・繰り下がりによる分類。
- [ちびむすドリル](https://happylilac.net/p-keisan.html) — 学年別の計算分類。
