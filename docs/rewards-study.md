## いちばん 大事な ところ（5行）

1. 毎日10分の子は **1週間 32こ・1か月 約130こ・1学期 約460こ**。1日 平均 4〜5こ（コードの 説明に ある「ふつうは 1日 1〜3こ」より 多い）。

## 1. 今の ごほうびの 一覧（コードを 正とした）

読んだ ところ：`data/collection.js`（`give`・`recordRun`・`yaRun`・`yaRank`・`KZ`・`DECOR`）、`data/masu100.js`（`reward`）、`index.html`（`colRun`・`m100Reward`）。README と 食いちがう ところは 見つかりませんでした（README に 書いていない ことは 下に「※」で 書きました）。

### 1-1. どんぐりが もらえる とき

| もらえる とき | 数 | 回数の 決まり |
|---|---:|---|
| ひろばを はじめて 開いた | 5 | 一生に 1回（1日の 上限に 入らない） |
| きょうの 1回め（5問以上・6割以上） | 1 | 1日 1回。※ゲーム・めもり名人・先生の クイズでも よい |
| 単元が「できた」（5問以上・7割の 回が **べつの日に もう1回**） | 2 | 単元ごとに 一生 1回 |
| 単元が「マスター」（「できた」の あと、**さらに べつの日に** 9割） | 3 | 単元ごとに 一生 1回 |
| 上の 2つで、自分の学年より **2学年以上 下**の 単元 | 1（ずつ） | 同じ |
| 先生の クイズ（3問以上 答えた） | 2 | 1日 1回。※協力の ロケット・ボスバトル（クラス）も これ。勝ち負けでは ふえない |
| 100マスの「数える回」（100問・9割・40秒以上・60分以内・最後まで） | 1回め 1／2回めから ½ | その日・その計算ごと。**100マスからは 1日 3こまで**。きのうの 回まで さかのぼる |
| もらえない もの | 0 | 1人用ボスバトル（数えない）・たんけんの 中の 正解・やりこみ（シール・じっせき）・にがて ボックス と サドンデスの 回の「できた」 |

**上限・ズルの 対策**

- 1日 **20こ** まで（100マスも 入れて）。あふれた 分は **持ちこし**（なくならない。つぎの日に 20こまで わたす）。
- 端末の 時計を もどす（記録した日より 前）と、どんぐりも 段階も 進まない（100マスも 同じ）。
- 「できた」「マスター」は **べつの日** が 必要 → 1日に 同じ 単元を 何回 やっても 進まない。
- 2学年以上 下の 単元は 少なめ（かんたんな 単元で かせげない）。
- ひろばが 完成して、きせかえも 全部 買ったら、どんぐりは もう ふえない。
- 記録は 端末の 中だけなので、書きかえれば 変えられる（成績には 使わない 前提）。
- ※授業モード（課題リンク `task=1`）：単元の 練習は どんぐりが **ふえる**（画面に 出ないだけ）。100マスは 授業モードでは **数えない**。先生の オフ・リンクの `col=0` では どちらも ふえない。

## 2. シミュレーション

`node tools/sim-rewards.js`（案ごとに `--plan A`／`B`／`C`／`BC`。50人ぶん 動かした **まん中の 値**。2分くらい）。本番の `recordRun`・`give`・`buy`・`kzBuy`・100マスの `reward` を そのまま 使っています。

**仮定**（わからない ところは 決めて 置いた）

- 1回の 練習＝1つの 単元を 10問（約3分）。毎日10分＝1日 3回。
- 正解の 確率は はじめ 72%（にがてな子は 50%）、その単元を やるたびに +4%（最大 97%）。
- 単元は 自分の学年 → 1つ下の学年の じゅん（どちらも 満額）。マスターしたら つぎの 単元へ。全部 終わったら ふくしゅう。
- 買い物は 買える中で いちばん 安い物から すぐ 買う（そのため「ひろば完成」と「全部 買い終わる」が 同じ日に なりやすい）。
- 「毎日」は 土日も ふくむ。週2回は 火・木。1学期＝15週（105日）。
- 単元の 数は `UNIT_IDS` の 280 全部を えらべると した（1年 35・2年 39・3年 57・4年 58・5年 55・6年 36。理科・英語・社会を ふくむ）。
- 100マスの子は 1日 6回（たし算・ひき算・かけ算を 2回ずつ）、単元の 練習は しない。

数字は「その日までに もらった どんぐりの 合計」。「単元が なくなる」＝満額の 単元を 全部 マスターした日（そのあとは ほぼ「きょうの1回め」の 1こだけ）。

## 3. 案

### 案A 今のまま

- **ほめる もの**：「できた」「マスター」に なること（べつの日に もう一度＝少し 時間を あけて できる）、毎日 1回 やること。
- **量と 値段**：ふつうの子で 1日 4〜5こ。全部で 593こ → 約4か月半。
- **よいところ**：もう 作って テスト済み。「べつの日」の 決まりで、たくさん やる子との 差が 天井で おさえられる。先生の 手間 なし。
- **心配なところ**：
  - 単元が なくなると（たくさん やる子 38日め・1年生 54日め）、1日1こに なって **2〜3か月 何も 買えない**。「もう やることが ない」と 感じて やめる かもしれない。
  - 100マスだけの子は きせかえが 買えない。
  - 後半は 高い かざりを 1か月 ためる 期間が ある。
- **変える ファイル**：なし。

### 案B ふくしゅうも ほめる（やり直し・くりかえしに どんぐり）

- **ほめる もの**：案A ＋「もう できた（マスター）単元を、べつの日に もう一度 9割」＝ふくしゅう。1単元 1日1回・**1日 2こまで** +1。わすれた ころに もう一度 やる ことを ほめる。
  （「まちがえた 問題を やり直す」＝にがて ボックスに +1 を つける 形も 考えられる。シミュレーションには 入れていない）
- **量と 値段**：ふつうの子で +15%（1学期 462 → 532）。単元が なくなっても 1日 3こ（1回め 1 ＋ ふくしゅう 2）は もらえる。
- **よいところ**：1年生・たくさん やる子・かんたん派の「止まる」問題が なくなる（1年生は 400日でも 終わらない → 161日め）。学習として 意味の ある「くりかえし」を ほめられる。
- **心配なところ**：たくさん やる子は 39日で 全部 買い終わる（早すぎるかも。→ お店の 品を ふやす か、Q1 で 決める）。もう できる 単元ばかり やって 新しい 単元に 進まない子が 出る かもしれない（1日 2こまでに しているので 小さい）。先生の 手間 なし。
- **変える ファイル（見こみ：小〜中）**：
  - `data/collection.js`：`recordRun` に ふくしゅうの 決まり（その日 ふくしゅうした 単元と 数を `S.day` に 持つ）、`clean` で 新しい 形を 読む。30〜40行。
  - `index.html`：`colRun` の 結果に「ふくしゅう どんぐり +1」の 1行と 文言（ふりがな）。5〜10行。
  - `tools/test-collection.js`：ふくしゅうの テスト（1日2こ・同じ日の 2回め・2学年下・時計もどし）。30行くらい。
  - README の 決まりの 節。
  - バックアップの 文字（HR）は 変えなくて よい（その日の 数だけなので）。

### 案C 上限を 10に 下げて、あそんだ日も ほめる

- **ほめる もの**：案A ＋「あそんだ日（5問以上・6割）が 5日に なるたび +3」。**れんぞくで なくて よい**（休んでも リセットしない＝罰に ならない）。かわりに 1日の 上限を 20 → **10** に（あふれた分は 今と 同じく 持ちこし）。
- **量と 値段**：ふつうの子は ほぼ 同じか 少し ふえる（1学期 525）。たくさん やる子は 1か月 426 → 296（ふつうの子の 3.2倍 → 1.9倍）。
- **よいところ**：差が ちぢむ。週2回の子・にがてな子も「来た 日」で もらえる。
- **心配なところ**：上限に 当たる 日が ふえるので、「きょうは もう もらえない」と 感じる 子が いる かもしれない（持ちこしで 減らない ことを 画面で 伝える 必要）。**1年生・かんたん派の「止まる」問題は 残る**（1年生は 260日め・かんたん派 325日め）。あそんだ日の 数は 新しく 記録が いる。
