# まなびひろば（試作品）

学校の端末で、すきま時間に遊べる学習ゲームのひろば。

## ファイル
- `index.html` … 本体（ダブルクリックでも一人用は遊べる）
- `server.js` … 友だち対戦用のサーバー（Node.js 標準機能のみ）
- `data/questions.js` … 漢字よみ・県庁所在地・英単語の問題（1問ごとに ID と学年）
- `data/calc.js` … 計算問題の自動生成（学年ごとの単元はファイル冒頭に記載）
- `data/choices.js` … 4択の選択肢の選びかた（漢字は長さ・送りがなをそろえる、英単語は同じ種類 c から選ぶ）
- `data/kanji-grade.js` … 学年別漢字配当表（AI作成・要人確認）
- `data/cooplib.js` … 協力モード「ロケット はっしゃ」の進行・判定（燃料・ミニゲーム・目標の式）。ブラウザ（先生の端末）と `server.js` が同じものを使う
- `data/quizlib.js` … 「先生がつくる もんだい」の部品（形式チェック・ルビ・表の取り込み・書き出し・れんしゅう用リンク・クイズの進行）。ブラウザと `server.js` が同じものを使う
- `tools/check-questions.js` … 問題の自動検査。`node tools/check-questions.js` でエラー0件になること
- `data/collection.js` … コレクション v1（じぶんの ひろば・たんげん ずかん・どんぐり）の中身。画面は持たず、`tools/test-collection.js` で単体テストする
- `data/hiroba-art.js` … ひろばの絵（SVG の symbol）。ひろばを開くときだけ読みこむ
- `tools/test-collection.js` … どんぐり・ずかん・バックアップの単体テスト。`node tools/test-collection.js`
- `tools/test-quiz.js` … 「先生がつくる もんだい」の部品の単体テスト。`node tools/test-quiz.js`

## 問題の確認状況
- 問題に付いている `reviewed:true` は、「読みと学年の配当はAIが全件確認した」という意味。**先生（人）の確認はまだ**（学校に出す前に、漢字だけでも先生に見てもらうと安心）。
- まちがえた問題のカードの「？ この もんだい、おかしい」を押すと、問題ID（例 `kanji-g3-035`）が出る。先生に見せてもらい、`data/questions.js` で直す。どこにも自動では送られない。

index.html は data フォルダと一緒に置くこと（ダブルクリックで開いても読めるよう script タグで読み込む）。

## 接続テスト
トップ下の「🔌 接続テスト」または先生の画面から開ける（`#check`）。友だち対戦に必要な通信ができるかを調べる。

## ルール（友だち対戦・バトルモード）
「やさしい」を選ぶと、たからばこで「うばう・入れかえ・落とす」が出ず、すごろくの🌀（もどる）がなくなる。1〜2年は「やさしい」が初期値。

## 友だち対戦（標準：先生の端末がサーバー役）
- 対戦用サーバーは不要。ページを置く場所（GitHub Pages など無料のところでOK）だけあればよい
- 端末どうしは WebRTC で直接つながる。最初の仲介だけ PeerJS の無料公開サーバーを使う
1. ページを http(s) で開く（試すだけなら このフォルダで `python -m http.server 8765` → http://localhost:8765/）
2. 先生役：「先生の画面」→「③ 部屋を作る」
3. 児童役：別のタブや端末で「🔑 コードで参加」→ 4けたのコード

注意：
- 先生の画面を閉じる・スリープすると対戦は止まり、部屋も消える
- 学校のネットワークによっては端末どうしの直接通信が止められ、つながらないことがある
- 無料の公開仲介サーバーは品質の保証がない（本番では自前の仲介サーバーかクラウドサービスを検討）

## 予備：対戦用サーバー経由
1. `node server.js` を実行
2. http://localhost:8787/?net=server を開く（`?net=server` をつけたときだけこの方式）
- 部屋はサーバーのメモリ上だけにあり、サーバーを止めると消える
- **上限（QA第3回）**：部屋づくりは同じ接続元（IP）から1分に6回・1時間に40回まで、同時に持てる部屋は接続元ごとに15、サーバー全体で400（超えると429／503）。誰も入らず誰も見ていない部屋は15分、何の操作もない部屋は45分、終わった部屋は30分で消える（最長3時間）。つなぎっぱなしの接続（SSE）は、1つの部屋に150、同じ児童／先生の資格情報に3、同じ接続元に200、鍵なしは接続元ごとに10、全体で4000まで。部屋の操作が20分ない接続は切り、送り切れない低速な接続（1MB以上たまる）も切る。値は環境変数 `LIMIT_*`（`server.js` の `LIM`）で変えられる（検査用）。`JOIN_RATE_SCALE` は部屋づくりの回数と接続元ごとの部屋数にも掛かる。検査は `node tools/test-server-limits.js`。

## 同梱している部品（vendor/）
外部（CDN）からは読み込まない。ライセンス全文は `vendor/THIRD-PARTY-LICENSES.txt`。 各ファイルの SHA-256 は `vendor/SHA256SUMS.txt`（`node tools/check-vendor-hashes.js` で現物と照合、部品を入れかえたら `--write` で作りなおす）。
- PeerJS 1.5.5（MIT）・qrcode-generator 2.0.4（MIT）・canvas-confetti 1.9.4（ISC）・ZzFX 1.4.0（MIT）
- 効果音・BGM・絵（CC0）：`vendor/audio/*.mp3`・`vendor/img/*.png`（約 0.8MB）。作者は Kenney（kenney.nl）と Juhani Junkala（OpenGameArt）。patch.gg（公開素材の検索）で CC0・非AI と確認して取得。クレジットは任意だが感謝として載せる。一覧と元URLは `vendor/THIRD-PARTY-LICENSES.txt`。音は「音オン」のときだけ読み込み、読めなければ ZzFX の音にもどる。BGM は先生の大画面の「BGM」ボタンを押したときだけ（初期オフ）
- アイコン：Lucide 1.71.0（ISC）。使う分だけを `index.html` の先頭に `<symbol>` として入れている（`#i-名前`）
- フォント：BIZ UDPGothic（OFL-1.1、@fontsource 5.3.0）。`vendor/fonts/biz-udpgothic.css` と `vendor/fonts/files/*.woff2`（使う文字を含む分割ファイルだけ）。font-display:swap。読み込めなくても端末のフォントで表示される。文言を増やして新しい漢字を使ったときは、フォントの分割ファイルを作り直す

## 見た目の決まり（3周目B）
- 色は `index.html` 先頭の CSS 変数（`--board` `--field` `--math` など）。押せる物だけ太いふち＋下影、押せない物は影なし
- 文字と背景のコントラスト比（WCAG、計算値）：白/黒板 9.6、黒板の補助文字 7.7、濃い文字/校庭 13.2、補助文字/校庭 6.9、白/算数の赤 4.8、白/国語の青 4.8、濃い文字/社会の黄 9.0、白/英語の紫 5.7、白/バトルの木 5.9、白/緑ボタン 5.3、濃い文字/橙（1分であそぶ）6.8、あと○もんの茶/白 7.8。すべて 4.5 以上
- 動きを減らす設定（prefers-reduced-motion）では、アニメーションと紙吹雪を止める

## じぶんの きろく（ログインなし）
- ホーム右上の「きろく」（`#record`）。メダルの合計と、ゲームごとの 🥉🥈🥇 のスタンプ帳。保存先はこの端末の localStorage だけ。名前・IDは集めない
- バックアップ：「MH2…」（v2。単元練習のベスト・メダルも入る。v1 の「MH1…」も読める）で始まる英数字だけの短い文字を出す／貼って読みこむ。中身は学年・ベスト・メダルだけ。読みこむときは、長さ・文字・確認の数字・範囲を調べ、正しいときだけ反映する（いまの きろくより大きい数字を残すので、きろくは減らない）。不正な文字は拒否
- 初期化ボタンは置かない（いたずら防止）。iPad（Safari）は長く使わないと保存が消えることがある、と画面に出している

## 先生がつくる もんだい（Kahoot型）
先生の画面の「④ もんだいを つくる」（`#make`）。ログイン不要・サーバー不要・外部への送信なし。保存はこの端末の localStorage だけ（`mh_quiz_sets`）。
- 問題：4択（2〜4個。正解は1つ以上＝複数にチェックすると どれを選んでも正解）と ○×。問題文120字・選択肢60字・1セット200問まで。制限時間は 5/10/20/30/60/90/120 秒（既定20、「ぜんぶ設定」あり）。得点は ふつう／2ばい／なし
- ルビ：`漢字《かんじ》` または `｜漢字《かんじ》`。画面では `<ruby>` を DOM で組み立てる（問題文を innerHTML に入れない）
- 取り込み：Excel・スプレッドシートの表をコピーして貼る（タブ区切り）か CSV ファイル（UTF-8／Shift_JIS）。列は `問題文｜選択肢1〜4｜制限時間(秒)｜正解の番号｜(得点)`（Kahoot のテンプレートと同じ順）。見出し行は自動で判定。空欄・範囲外の時間は20秒。取り込む前に行ごとに ✅／⚠️（直して取り込む）／❌（理由つき）を表示。テンプレートCSVのダウンロードあり。.xlsx は読めない（Excel で表をコピーして貼る）
- 書き出し：`.json`（`{format:"manabi-quiz",v:1,...}`）、CSV（UTF-8 BOM。Excel で開ける）、れんしゅう用リンク＋QR（`#q=` の後ろに deflate-raw 圧縮＋base64url。圧縮に対応しないブラウザは無圧縮。8000文字をこえたらファイルを案内、QRは約2300文字まで）。リンクを開いた児童はひとりで解ける
- ライブ出題：先生の画面「③ クラスで友だち対戦」で あそびかた「クイズ」と先生のセットを選ぶ。大画面＝問題・選択肢（赤▲青◆黄●緑■）・のこり時間の帯・回答人数、児童＝色と形の大ボタン。時間切れか全員回答で正解と分かれ方→先生が「つぎへ」。3問ごとに上位5人、最後に表彰台と問題ごとの正答率（CSV保存、正答率60%未満の問題だけ「もう一度」）。得点は 500＋500×のこり時間/制限時間（2ばい×2、なし0）、連続正解は🔥の表示だけ。やさしいルールは順位を出さず「みんなで ○もん せいかい！」
- たからばこ・すごろくでも、問題の出どころに先生のセットを選べる（4択だけ。制限時間は使わない）
- 通信：標準（PeerJS・先生の端末が進行役）と `?net=server`（`server.js`）の両方で動く。答えは出題中は児童の端末に送らず、点数は先生の端末（またはサーバー）が決める。受け取ったデータ（貼りつけ・ファイル・リンク・通信）は、型・文字数・個数・時間の値を調べてから使う

## 単元ごとの問題の型（data/units.js・data/gen/*.js）
- `data/units.js` … 単元の一覧 `UNITS`（教科 › 学年 › 単元、領域・指導要領メモ・学習項目タグ・例題・段階）、`unitPick(単元ID[], 問題数, シード, まぜる)`、おすすめの組み合わせ `UNIT_SETS`、答えの判定 `MH_UNITS.check`
- `data/gen/*.js` … 算数の「問題の型」（数字を変えて何問でも作れ、正解はコードで計算）。国語・社会・英語は既存データ（questions.js）を単元で切り出す（`other.js`）
- 読み込み順：kanji-grade → questions → choices → gen/core → gen/* → units（まだ index.html には組み込んでいない）
- 検査：`node tools/check-units.js`（各型を1,000回作る。エラー0件になること）

## ふりがな（問題データの読み《》）
児童に見せる文字の漢字には、読みを `漢字《かんじ》`／`｜3人《さんにん》`（数字つきの読み）の形でデータに入れてある（書き方・取り出しは `data/quizlib.js` の `rubyParts`／`plain` と同じ）。
- **付けてある所**：単元の `title`・`note`・`ex`・`stepLabel`、`UNIT_SETS` の名前、`MH_UNITS.make()` が返す `q`・`a`・`choices`・`stem`、県庁（`q` 県名・`a` 県庁名。`r` は読みデータとしてそのまま残す）、英単語の意味 `a`、計算（`calc.js`）の単元名と `small`。
- **付けない所（先生向けの分類名）**：単元の `item`・`base`・`area`・`series`。
- **例外（答えになるので付けない）**：漢字よみクイズの「問われている漢字」。データでは `MH_QUESTIONS.kanji[].q`、単元では「漢字の読み」（gen=`kanjiYomi`）の `make()` が返す `q`（`src` が `kanji-…` の問題）。表示側でも、この `q` はふりがなを付けずに出す。問題文の残り（`stem`）と選択肢（かな）は通常どおり。
- **書き方の決まり**：熟語は熟語ごと（面積《めんせき》）、送りがなは外に出す（長《なが》さ）、数字つきのかぞえ方は数で読みが変わる（`｜1人《ひとり》`・`｜2日《ふつか》`・`10分《ぷん》`・`5分《ふん》`・`｜4時《よじ》`）。
- **比べ方**：正解の判定・選択肢の重複・文字数の比べ・学年配当の検査は、読みを取り除いた本文（`plain`）でする。`MH_UNITS.check`／`canon` は《》付きの入力でも本文で比べる。`MH_UNITS.make()` の `val` は本文。
- **読みを付ける部品**：`MH_GEN.ruby(文字列)`（`MH_UNITS.ruby` と同じ。辞書は `data/gen/core.js` の `FURI_WORDS`。すでに《》のある所は触らず、何回かけても同じ）／`MH_GEN.plain(文字列)`（読みを取り除く）。新しい文言に漢字を使ったら、`FURI_WORDS` に「読みを付けた形」で足す。足りなければ検査が教えてくれる。
- **検査**：`node tools/check-furigana.js`（各型を1,000回作り、読みの付いていない漢字が0であること／漢字よみの `q` に《》が付いていないこと）。

## ふりがな（表示側）と、前の大画面／児童の画面（4周目）
- **表示**：文字の中の `漢字《かんじ》` は、画面に出るとき `index.html` の `fgWalk`（MutationObserver）が `<ruby>` に組み立てる（innerHTML には入れない。属性・`<option>`・SVG の文字は読みを除く）。右上の「ふりがな あり／なし」（既定あり、localStorage `mh_fg`）は `<rt>` を CSS で隠すだけ。授業モードの課題リンクに `fg=0/1` を付けると先生が固定できる（先生の画面の「ふりがな」欄）。
- **漢字よみクイズ**の問われている漢字は、データ側で読みなし。先生がつくる もんだいの作成・取り込みでは、読みのない漢字を「ふりがなの ない 漢字：…」と注意する（取り込みは止めない）。
- **検査**：`node tools/check-furigana-ui.js`（TX の両側と、script 内の児童向けの文字に、読みのない漢字が0）。先生向けの所は T-BEGIN／T-END の印か行末の `//T` で除外。`node tools/check-furigana.js` はデータ側。
- **先生の端末＝前に映す大画面**（`renderHost`）：待合室はコードとQRを最大／たからばこは順位の棒・のこり時間・できごと／すごろくは盤を画面いっぱい＋上位3人。最小28px、操作ボタンは右下の dock（全画面・先生用メモ・終わる）。できごとは前回の状態との差から作るので、通信データ（PeerJS／?net=server）は変えていない。クイズの先生画面は今のまま（ボタンだけ右下）。
- **児童の端末＝自分がやることだけ**：問題・答え・自分の点と順位・ごほうび。全体の順位表・盤・他の人の名前は出さない（待合室は人数だけ、結果は自分の行だけ）。
- **児童が入力する名前（友だち対戦）**：参加時に「なまえを いれてね」（1〜8文字。ひらがな・カタカナ・漢字・英数字。名前の下に「本当の名前は入れないで、あだ名にしてね（クラスのみんなに見えるよ）」と出す。名前は初期設定では覚えない（このタブの sessionStorage `mh_name_s` だけ）。「この たんまつは じぶんだけ」にチェックを入れたときだけ localStorage `mh_name` に保存し、外して参加すると `mh_name` を消す）。先生の「なまえの きめかた」は、**はじめから「自動ニックネーム」**（先生が「児童が入力」にもできる）。※以前の「自動ニックネームにもできる」（`#teacher?nm=auto` でえらんだ状態にできる）。検査は `data/ngwords.js`（自作の短いNG語リスト。かな・ローマ字・全角半角のゆれをそろえて部分一致。漢字の悪口（馬鹿・死ね・殺す など）は別のリストでそのまま部分一致。「しねしね」のようなくり返しも断る。リストは完全ではないので、先生が名前を押して変えられる）を、児童の端末・先生の端末（PeerJS）・`server.js` の3か所で同じように行う。同じ名前は「ゆうと2」と番号をつける。
- **名前の扱い**：名前は先生の端末（`server.js` ならそのメモリ）にだけ持ち、部屋を閉じると消える。localStorage・ログには残さない（児童が「この たんまつは じぶんだけ」を選んだ `mh_name` を除く）。児童の端末には、ほかの子の名前を送らない（自分の名前だけ `me`）。先生の大画面で名前を押すと「名前をかえる／ニックネームにする／へやから出す」。結果のコピー・CSVに名前を入れるかは先生がえらぶ（既定は入れない。入れないときは「児童1…」）。
- **大画面の吹き出し**：動いた子のアイコンの上に、名前を約1.2秒（最大5つ、まだ出ていない子を先に、同じ子は続けて出さない）。出すのは、待合室の参加・たからばこでコインをふやした・すごろくで進んだ・ゴール。まちがい・失点・もどる・うばわれた側・最下位は出さない。クイズの「答えた」は、名前も正誤も出さず動物の絵だけ。reduced-motion ではフェードのみ。検査：`node tools/test-names.js`。
- **単元練習の記録**：単元ごとのベストとメダルを `mh_best` の `u:<単元ID>` に残す（きろく画面の「たんげん」、メダル合計に入る）。



## じぶんの ひろば・たんげん ずかん・どんぐり（コレクション v1）
- 勉強したあとが形になる場所。ランキング・名前・あげもらい・くじ・課金・広告・外部送信はありません。保存先はこの端末の localStorage（キー `mh_col`）だけ
- 「できた」＝単元ごとに 5問以上・○7割以上の回が、べつの日にもう一度ある。「マスター」＝さらにべつの日に 5問以上・○9割以上。どんぐり：できた +2／マスター +3（項目ごと一生1回。2学年以上下の単元は +1）、きょうの1回め +1、先生のクイズ +2、はじめの5こ（1回だけ）。1日 20こまで、あふれた分は あしたに持ちこし。記録した日より前の日付（時計を戻した）のときは増えない
- 先生：先生の画面の「⑥」で、この端末のオン／オフ。授業モード（task=1）では画面に出ない（記録だけ）。リンクの `col=0` で そのリンクだけオフ。**オフが優先**で、オフの端末では `col=1` でもオンにならない
- バックアップ：きろく画面の「ひろばの もじ（HR1）」。変わった分だけの短い文字（3年1学期ぶんで 150字以下）と QR を出す。読みこみは形式・確認の数字・範囲を調べ、記録が減らない合成。MH1／MH2 はそのまま。ひろばは原則その端末のもの（引きつぎは例外）
- 単元を増やしたら `data/collection.js` の `UNIT_IDS` に足す（`test-collection.js` が食い違いを知らせる）

## 児童の名前・参加まわりの安全（個人情報レビュー 第3回への対応）
- **途中参加の制限**：ゲームが始まったあとの参加は断る（クイズ・たからばこ・すごろくとも。待合室だけ入れる）。先生の画面の待合室にある「入室をしめきる」を押すと、始める前でも参加を止められる（「しめきりを やめる」であけなおせる）。すでに入っている子の再接続は、そのまま通る。
- **名前に電話番号・メール・URL らしい文字**：数字が5けた以上つづく名前、数字が合わせて7けた以上の名前、http・www・メール会社名（gmail など）を含む名前は断る（`data/ngwords.js` の `isContact`、why は `pii`）。児童の端末・先生の画面・`server.js` で同じ部品を使う。`@ . / : -` は文字の種類の検査で先に断られる。
- **コードの総当たり対策**：4けたのコードは公開仲介サーバー（0.peerjs.com）の上で誰でも試せるので、先生の端末（`server.js` も同じ考え方）で join のくり返しを制限する。P2P：1つの接続から10秒に5回まで、部屋全体で1秒に10回まで、つながる数は200まで、同じ接続でもう一度 join したら前の分を外す（1つの接続で人数をふやせない）。`server.js`：部屋全体で1秒に10回まで。同じ接続元（IPアドレス）からは、失敗した試し（コードちがい・名前の不備）が10秒に5回まで、成功は10秒に30回まで（教室の端末は同じ接続元に見えることがあるので、成功のほうはゆるくしている）。止められた子には「しばらくしてから、もう一度ためしてね」と出る。環境変数 `JOIN_RATE_SCALE` で上限を何倍かにできる（検査用）。コードを外の人に知られたときは、「先生の画面」にもどって部屋を作りなおすと新しいコードになる。
- **結果のCSV**：名前を入れる設定は既定でオフ。`= + - @` タブ で始まる文字には `'` を付けて、表計算ソフトで数式として動かないようにしている（`data/quizlib.js` の `csvSafe`。ただの数字はそのまま）。このCSVを取り込み直すと、先頭に `'` が付いた問題文になるので、やりとりには JSON を使うこと。
- **クイズ終了時の○×の記録**：先生の画面には全員ぶん（`rec`）を送るが、児童の端末には自分の分（`myrec`）だけを送る。
- **予備サーバーの鍵**：先生の鍵（hostKey）と児童の参加 token は、URL ではなく POST `/api/events` の本文で渡す（`fetch` のストリームで受け取る）。GET `/api/events?code=` は鍵なし（名前が見えない）の接続だけ。サーバーはリクエストの中身をログに出さない。
- **小人数の部屋**：2人以上のとき、順位の表は最下位の子の名前を出さない（`pxVis`）。
- **`esc()`**：`'` も変換するようにした。
- **対応しなかったもの**：S5（`server.js` は全インターフェースで待ち受け、HTTP は平文）…校内LANの予備として使い、インターネットには公開しないこと（コードは変えていない）。S6（たからばこ・すごろくの自己申告の得点）…個人情報ではなくふざけ対策の範囲なので、今回は変えない（クイズは先生の端末で採点している）。S8（Kahoot など外部リンク）…学校の許可が要るので、学校ごとに確認する（授業用リンク task=1 では出ない）。S10（バックアップ文字は確認3桁だけ）…個人の識別はできず、ランキングには使っていない。学習の信用に関わるので、今後もランキングには使わないこと。
- **人の判断が必要**：児童が自由に入れる名前を個人情報として扱うか（学校・自治体の方針。最小化のため「自動ニックネーム」を選べる）／公開仲介サーバー（海外）経由の通信を学校のセキュリティポリシーが許すか。

## 先生向けの説明文（先生の画面の「つかう まえに」と同じ。保護者向け文書にも使える）
1. 名前は児童が自由に入力します。本名（名字）ではなく、あだ名を入れるよう声をかけてください。名前は先生の端末のメモリにだけ置き、部屋を閉じると消えます。
2. 先生の画面を教室の大画面に映すと、児童の名前がクラス全員に見えます。上位の子と、動いた子の名前だけが出ます（最下位の子の名前は出しません）。全員の表は「先生だけ みる」を押したときだけ開きます。気になる名前は、名前を押すと「かえる／ニックネームにする／へやから だす」ができます。
3. 共用の端末では、前の子の名前が次の子の入力欄に出ないよう、名前は初期設定では覚えません（このタブを閉じると消えます）。児童が「この たんまつは じぶんだけ」を選んだときだけ、その端末に名前を残します。共用の端末では選ばないよう伝えてください。
4. 結果のCSV・コピーに名前を入れるかは先生が選べます（初期設定は入れません）。名前入りのファイルは、学校の個人情報の扱いに従って保管・削除してください。
5. 4けたの部屋コードは、インターネット上の公開仲介サーバー（0.peerjs.com）を通じて端末どうしをつなぎます。コードを教室の外に出さず、全員がそろったら「入室をしめきる」を押してください。ゲームが始まったあとは入れません。同じ端末からの続けての参加は一定時間ごとに数を制限しています。コードを知られたときは、「先生の画面」にもどって部屋を作りなおすと新しいコードになります。
6. 通信先は 0.peerjs.com（仲介）、stun.l.google.com（STUN）、*.turn.peerjs.com（直接つながらないときの中継）だけです。これらにはIPアドレスが届きますが、名前や得点は届きません（端末どうしの通信は暗号化されます）。
7. ひろば・どんぐり・ずかんは、この端末の記録だけで動き、名前・順位・外部送信はありません。授業で使わないときは「⑥」でオフにできます。リンクの col=0 でもオフにできます。
8. 記録は、その端末の遊びの記録で、成績の証明には使えません。どんぐり・ずかん・自己ベスト・バックアップの文字は、端末の中の記録で、本人が書きかえることもできます（端末の時計を変えても数字が変わります）。通知表・評価・順位づけには使わないでください。

## 読み込みの計測

`node tools/measure-load.js` による静的見積もり：初回 19 ファイル・875,514 バイト（未圧縮、キャッシュなし）。うちホームの静的表示に必要なフォントは 4 ファイル・101,664 バイト。実転送量・時間ではなく、動的表示による追加フォントや通信も含みません。かな＋学年までの漢字を少数のフォントファイルにまとめればリクエスト数を減らせますが、同じ字形を重複収録するとバイト数は増え得ます。まず実機で転送量と所要時間を測り、統合前後を比較して採否を決めます。

## 協力モード「ロケット はっしゃ」
クラス全員で1つのロケットを飛ばす協力モード（先生の画面の「① クラスで友だち対戦」→ あそびかた「ロケット はっしゃ（みんなで きょうりょく）」）。問題は「問題」で選んだもの（既存のゲーム・先生のもんだい・単元から作ったセット）の4択。
- **流れ（ふつう5ステージ・約5分／みじかい3ステージ・約3分。先生が部屋づくりの「ステージの数」でえらぶ）**：問題タイムで燃料をためる（正解＋5・答えたら＋1・1人の上限あり）→ ゲージが目標に届くとミニゲーム（全員同時・15〜25秒）→ クリアで次のステージ（くも→そら→うちゅう→つき→ほし）。ミニゲームは「せーので はっしゃ」（3・2・1 の「1」で押す。先生の時計に合わせて、前後0.6秒で「ぴったり」。クラスの6割がぴったりでクリア）と「ほしを あつめよう」（自分の端末の流れ星をタップ。全員の合計で判定・1人の上限あり）。失敗しても「もういちど」は1回だけ。2回目は条件をゆるめ（ぴったり1.2秒・割合25%・ほしは半分）、足りなくても必ず次へ進む。燃料が届かなくても、問題タイムは最長60秒で次へ進む。
- **目標の自動調整**：1ステージの目標＝人数×（1分に答える数：1〜2年4／3〜4年5.5／5〜6年6.5）×基本時間（50秒・やさしいは45秒）×平均燃料×参加率0.85×むずかしさ（ふつう0.7・やさしい0.55）。最小10。時間の6割で45%未満なら「おいかぜ」（以後1.25倍）。ブーストは1人1ステージに1回（＋2）で、6割が押すと全体に＋10%。
- **出さないもの**：個人の正誤・順位・燃料の数字（児童には％と「みんなの ばん！」だけ）。大画面に名前が出るのは良いことの吹き出し（正解・ブースト・ミニゲーム）だけで、1秒に最大2つ・同じ子は20秒に1回・まだ出ていない子を優先。児童の画面に他の子の名前は出ない。どんぐりは、3問以上答えた子に＋2（1日1回。先生のクイズ参加と同じ。成功してもふえない）。
- **通信**：進行・判定は `data/cooplib.js`（ブラウザの先生の端末と `server.js` が同じ部品）。状態 `co` は小さく（最大でも約200バイト・700バイト以下）、250msにまとめて送る。対戦中は人の一覧を送らない（先生の画面だけが名前つきの一覧を受け取る）。PeerJS は詰まった接続にはその回だけ送らない。児童の操作は `cans`（答えた）・`boost`・`mini` の3つだけで、型・範囲・連番・間隔を先生の側で調べる。`server.js` も同じ検証。
- **絵**：`data/rocket-art.js`（ロケット・炎・発射台・流れ星・ステージ背景6枚ほか。このモードに入るときだけ読み込む）。動きは `prefers-reduced-motion` で止まる。
- **検査**：`node tools/test-coop.js`（燃料・目標・1人の上限・ミニゲームの判定・2回目の救済・状態の大きさ・60人のシミュレーション・`server.js` の検証）。

## 4周目（前半）：授業モード・ひろばを切る・先生の画面・ロケットの密度
- **名前の既定（ユーザー決定）**：部屋づくりの「なまえの きめかた」は、はじめから「自動ニックネーム」。先生が「児童が入力する」を選べる（`#teacher?nm=input`）。`server.js` に何も送らないときの値は従来どおり「入力」（検査 `test-names.js`）。
- **授業モード（task=1）の対象**：課題リンク・単元リンク（`#u=…&task=1`）・れんしゅう用リンク（`#q=…&task=1`）。ロゴ無効・「ここでおわる」だけ・ひろばの入口なし。結果に「先生に送る結果」（単元：単元名と ○△×の数とまちがえた問題ID／クイズ：セット名・正解数・まちがえた問題の番号）。「単元をえらぶ」の「リンクとQR」「れんしゅう用リンクを作る」に「授業で使う」のチェック。`#units?pick=`（ガイドから）は、はじめからオン。
- **ひろばを「クラスぶん」切る**：課題リンク・単元リンク・れんしゅう用リンクの作成欄の「ひろばを出さない」で `&col=0` が付く。部屋づくりの「ひろばを出さない」（はじめからオン）は部屋の設定 `nh`（1＝出さない）として児童に届き、友だち対戦（ロケット・クイズ）の結果画面にどんぐりの行と「ひろばを みる」を出さない（オフにすると出る）。⑥の設定は「いま開いているこの端末だけ」。
- **先生の画面**：上に「クラスで遊ぶ／リンクを配る／問題をつくる」の3つ（`#teacher?tab=link|make`）。番号は ①友だち対戦 ②教室で映すクイズ ③課題リンク ④単元から ⑤先生のもんだい ⑥ひろば。前回の「あそびかた・問題・学年」は localStorage `mh_troom` に覚える。1280×720 で、開いてから「部屋を作る」までスクロールなし。待合室の「スタート！」は大きな緑。
- **ロケットの密度**：ミニゲーム1回は12秒以内（せーので10秒・ほし11秒）。問題タイムの基本時間を 50秒に、クリア・もういちどの間を短くした。終了画面に「クラスで ○もん こたえた」。`test-coop.js` に、30人×（ふつう・みじかい）×（2・4・6年）で「1人あたりの解答数がたからばこ（同じ時間・同じ速さ）の7割以上」の検査（いまは約72〜78%）。
授業リンクはタブ単位の sessionStorage に保持し、URL 書き換えや戻る操作では解除できません。ただし新しいタブで普通に開けば通常モードであり、児童端末の JavaScript だけで授業中の画面移動を完全には止められません。
データを更新したら `node tools/stamp-version.js`。
