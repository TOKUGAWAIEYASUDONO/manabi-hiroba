# まなびひろば（試作品）

学校の端末で、すきま時間に遊べる学習ゲームのひろば。

## ファイル
- `index.html` … 本体（ダブルクリックでも一人用は遊べる）
- `server.js` … 友だち対戦用のサーバー（Node.js 標準機能のみ）
- `data/questions.js` … 漢字よみ・県庁所在地・英単語の問題（1問ごとに ID と学年）
- `data/calc.js` … 計算問題の自動生成（学年ごとの単元はファイル冒頭に記載）
- `data/choices.js` … 4択の選択肢の選びかた（漢字は長さ・送りがなをそろえる、英単語は同じ種類 c から選ぶ）
- `data/kanji-grade.js` … 学年別漢字配当表（AI作成・要人確認）
- `tools/check-questions.js` … 問題の自動検査。`node tools/check-questions.js` でエラー0件になること

## 問題の確認状況
- 問題に付いている `reviewed:true` は、「読みと学年の配当はAIが全件確認した」という意味。**先生（人）の確認はまだ**（学校に出す前に、漢字だけでも先生に見てもらうと安心）。
- まちがえた問題のカードの「？ この もんだい、おかしい」を押すと、問題ID（例 `kanji-g3-035`）が出る。先生に見せてもらい、`data/questions.js` で直す。どこにも自動では送られない。

index.html は data フォルダと一緒に置くこと（ダブルクリックで開いても読めるよう script タグで読み込む）。

## 接続テスト
トップ下の「🔌 接続テスト」または先生の画面から開ける（`#check`）。友だち対戦に必要な通信ができるかを調べる。

## ルール（友だち対戦・バトルモード）
「やさしい」を選ぶと、たからばこで「うばう・入れかえ・落とす」が出ず、すごろくの🌀（もどる）がなくなる。1〜2年は「やさしい」が初期値。

## 友だち対戦（標準：先生の端末がサーバー役）
- 対戦用サーバーは不要。ページを置く場所（GitHub Pages など無料のところでOK）だけあればよい
- 端末どうしは WebRTC で直接つながる。最初の仲介だけ PeerJS の無料公開サーバーを使う
1. ページを http(s) で開く（試すだけなら このフォルダで `python -m http.server 8765` → http://localhost:8765/）
2. 先生役：「先生の画面」→「③ 部屋を作る」
3. 児童役：別のタブや端末で「🔑 コードで参加」→ 4けたのコード

注意：
- 先生の画面を閉じる・スリープすると対戦は止まり、部屋も消える
- 学校のネットワークによっては端末どうしの直接通信が止められ、つながらないことがある
- 無料の公開仲介サーバーは品質の保証がない（本番では自前の仲介サーバーかクラウドサービスを検討）

## 予備：対戦用サーバー経由
1. `node server.js` を実行
2. http://localhost:8787/?net=server を開く（`?net=server` をつけたときだけこの方式）
- 部屋はサーバーのメモリ上だけにあり、サーバーを止めると消える

## 同梱している部品（vendor/）
外部（CDN）からは読み込まない。ライセンス全文は `vendor/THIRD-PARTY-LICENSES.txt`。
- PeerJS 1.5.5（MIT）・qrcode-generator 2.0.4（MIT）・canvas-confetti 1.9.4（ISC）・ZzFX 1.4.0（MIT）
- アイコン：Lucide 1.71.0（ISC）。使う分だけを `index.html` の先頭に `<symbol>` として入れている（`#i-名前`）
- フォント：BIZ UDPGothic（OFL-1.1、@fontsource 5.3.0）。`vendor/fonts/biz-udpgothic.css` と `vendor/fonts/files/*.woff2`（使う文字を含む分割ファイルだけ）。font-display:swap。読み込めなくても端末のフォントで表示される。文言を増やして新しい漢字を使ったときは、フォントの分割ファイルを作り直す

## 見た目の決まり（3周目B）
- 色は `index.html` 先頭の CSS 変数（`--board` `--field` `--math` など）。押せる物だけ太いふち＋下影、押せない物は影なし
- 文字と背景のコントラスト比（WCAG、計算値）：白/黒板 9.6、黒板の補助文字 7.7、濃い文字/校庭 13.2、補助文字/校庭 6.9、白/算数の赤 4.8、白/国語の青 4.8、濃い文字/社会の黄 9.0、白/英語の紫 5.7、白/バトルの木 5.9、白/緑ボタン 5.3、濃い文字/橙（1分であそぶ）6.8、あと○もんの茶/白 7.8。すべて 4.5 以上
- 動きを減らす設定（prefers-reduced-motion）では、アニメーションと紙吹雪を止める

## じぶんの きろく（ログインなし）
- ホーム右上の「きろく」（`#record`）。メダルの合計と、ゲームごとの 🥉🥈🥇 のスタンプ帳。保存先はこの端末の localStorage だけ。名前・IDは集めない
- バックアップ：「MH1…」で始まる英数字だけの短い文字（60文字ほど）を出す／貼って読みこむ。中身は学年・ベスト・メダルだけ。読みこむときは、長さ・文字・確認の数字・範囲を調べ、正しいときだけ反映する（いまの きろくより大きい数字を残すので、きろくは減らない）。不正な文字は拒否
- 初期化ボタンは置かない（いたずら防止）。iPad（Safari）は長く使わないと保存が消えることがある、と画面に出している
