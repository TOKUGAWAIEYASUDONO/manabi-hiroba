保護者・学校向け運営とデータの扱い

まなびひろばは、個人が開発・運営する無料の学習ゲームです。登録も広告もありません。お問い合わせ・不具合の報告は GitHub リポジトリの Issues へお願いします。公開投稿なので、児童の個人情報は書かないでください。

集めない物・端末に残る物

このサイトの運営者は名前、メールアドレス、アカウント、位置情報、成績を収集しません。端末には学年・遊びの記録・どんぐり・ふりがな等の設定が保存されます。主な保存キー：mh_setup、mh_best、mh_col、mh_colcfg、mh_fg、mh_ui、mh_sound、mh_quiz_sets、mh_upick、mh_troom。対戦中の一時情報：mh_net、mh_host、mh_name_s。授業リンクの固定には、このタブだけに mh_lesson_hash を使います。自分専用の端末と指定した場合だけ mh_name に名前が残ります。共有端末では指定しないでください。記録は端末で遊んだ履歴であり、成績評価には使えません。

対戦時の名前・通信

名前は既定では自動ニックネームです。先生が名前入力を選んだ場合だけ児童が入力できます。

通常方式：GitHub Pages ＋ PeerJS

通常のサイト表示は GitHub Pages から配信されます。友だち対戦では 0.peerjs.com（接続仲介）と STUN/TURN（stun.l.google.com・*.turn.peerjs.com、接続補助・中継）にも通信します。これらには接続に必要な IP アドレスが届きます。対戦用の名前や得点は先生の端末のメモリに置かれ、部屋を閉じると消えます。

予備方式：学校が動かす node サーバー（?net=server）

学校が自分で server.js を動かす場合、対戦中だけ、その学校のサーバーのメモリに名前（または自動ニックネーム）・得点・正誤が置かれます。部屋が消えると、これらも消えます。このサーバーとデータを管理するのは、サーバーを動かした学校です。通常方式の PeerJS ではなく、学校のサーバーに接続します。
